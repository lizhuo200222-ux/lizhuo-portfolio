# 李卓 AI 电商视觉作品集设计说明

## 目标

把简历中的复合能力（3D 视觉、AI 内容生产、电商自动化、网页/工具产品）整理成一个可运行的单页作品集基础版本，让招聘方在 30 秒内理解定位、证据和联系方式。

## 结构

1. 全屏 Hero：视频背景（带海报回退）、顶部导航、主定位和联系按钮。
2. About / Experience：头像、简介、三项结果数据、经历时间线与联系信息。
3. Selected work：两个大幅项目卡片，使用本地真实作品图，分别呈现 AI 商业视觉和电商数据自动化。
4. Strengths：以不等宽的能力单元呈现 3D、AI 工作流、自动化/网页三条能力线。
5. Contact：整屏深色收尾，只有一个主要联系动作，避免重复 CTA。

## 视觉系统

- 页面主题：深色；背景 `#0b0d0f`，表面 `#15191d`，文字 `#f0f2ed`，次级文字 `#98a29f`。
- 唯一强调色：冷青绿 `#74d8c4`，用于链接、数据和焦点状态。
- 版心：`min(1700px, calc(100% - 64px))`，移动端缩减为 24px 边距。
- 字体：系统无衬线 + 等宽数字，避免依赖外部字体服务。
- 圆角：卡片 18px，按钮使用 999px，保持一个明确的形状规则。
- 动效：入场淡移、作品卡 hover 轻微缩放、背景视频慢速播放；尊重 `prefers-reduced-motion`。

## 工程边界

- React + Vite，静态内容数据集中在 `src/data.js`。
- 不引入后端或表单提交；邮箱/电话使用标准 `mailto:`/`tel:` 链接。
- 视频使用远程 mp4 源并提供本地作品图 poster 和错误回退，断网时页面仍可读。
- 所有图片使用真实本地素材，图片加载失败显示可理解的占位状态。

## 验收

- `npm run build` 通过。
- 桌面 1440px 和移动 390px 截图无溢出、无遮挡。
- 导航锚点、邮箱、电话可点击；作品卡 hover 与 reduced-motion 有合理行为。
