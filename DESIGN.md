# Design System

## Theme

Dark editorial portfolio with a restrained technical mood. The physical scene is a designer reviewing commercial visual work on a large monitor in a dim studio, where the artwork is the brightest evidence and the interface stays quiet around it.

## Color

- Canvas: `#0b0d0f`
- Surface: `#15191d`
- Text: `#f0f2ed`
- Muted text: `#98a29f`
- Single accent: `#74d8c4`
- Supporting accents: `#c3df82`, `#e7a16d`

## Typography

System sans for Chinese copy, restrained display scale, and monospace metadata for dates and indexes. Headings are left aligned and capped at two to three lines per composition.

## Layout

Use a `min(1700px, 100% - 64px)` shell. Prefer asymmetric editorial grids and stable media aspect ratios. Cards only frame independent project objects; page sections stay unframed. Keep project categories visibly mixed so a single IP case does not define the whole portfolio.

## Motion

Use slow image drift, a restrained light sweep, hover lift, and short ease-out reveals only to establish hierarchy. All motion has a reduced-motion fallback and never changes layout dimensions.
